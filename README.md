# EstateAI - House Price Prediction

A premium machine learning web application that predicts house prices based on area, bedrooms, and bathrooms using advanced regression analysis.

## 🎯 Features

- **Interactive Web Interface** - Beautiful, responsive UI built with Flask
- **ML Model** - Linear Regression trained with Scikit-learn
- **Real-time Predictions** - Get instant property valuations
- **Modern Design** - Glassmorphism UI with smooth animations
- **Error Handling** - Robust input validation and error management
- **Mobile Responsive** - Works seamlessly on all devices

## 📋 Prerequisites

- Python 3.8 or higher
- pip (Python package manager)

## 🚀 Quick Start

### 1. Installation

Clone the repository:
```bash
git clone https://github.com/ahsanali226/predict-price-.git
cd predict-price-
```

Install dependencies:
```bash
pip install -r requirements.txt
```

### 2. Train the Model

Run the ML training script to generate `model.pkl`:
```bash
python ml.py
```

**Expected Output:**
```
Model Training Score: 0.8xxx
Model Test Score: 0.8xxx
✓ Model Trained and Saved Successfully as 'model.pkl'
```

### 3. Run the Application

Start the Flask server:
```bash
python app.py
```

**Expected Output:**
```
* Running on http://127.0.0.1:5000
```

Open your browser and navigate to: `http://localhost:5000`

## 📊 How It Works

1. **Input Features**: Enter property details:
   - Area (Square Feet)
   - Number of Bedrooms
   - Number of Bathrooms

2. **Prediction**: Click "Calculate Valuation" to get an estimated price

3. **Results**: Receive instant property valuation with formatted price output

## ⚠️ Error Handling

The application handles:
- ❌ Missing `model.pkl` - Guides user to run `ml.py`
- ❌ Invalid input values - Shows error messages
- ❌ Negative numbers - Rejects invalid inputs
- ❌ Type mismatches - Validates numeric inputs

## 🔍 Troubleshooting

### Issue: `FileNotFoundError: model.pkl not found`
**Solution**: Run `python ml.py` first to generate the trained model

### Issue: `ModuleNotFoundError: No module named 'flask'`
**Solution**: Install dependencies with `pip install -r requirements.txt`

### Issue: Port 5000 is already in use
**Solution**: Edit line 31 in `app.py`:
```python
app.run(debug=True, port=5001)  # Use a different port
```

### Issue: CORS or connection errors
**Solution**: Ensure Flask is running and accessible at `http://localhost:5000`
